# Estudos de Go

[![Go](https://img.shields.io/badge/Go-00ADD8?style=for-the-badge&logo=go&logoColor=white)](https://go.dev/)

> Este repositório contém minhas anotações e códigos de estudo da linguagem Go.

## Conceitos Principais

### Fundamentos
- **Goroutines**: Concorrência leve e eficiente
- **Channels**: Comunicação entre goroutines
- **Interfaces**: Tipos abstratos para polimorfismo
- **Defer**: Execução garantida de funções
- **Error Handling**: Tratamento explícito de erros

### Estruturas
- **Structs**: Tipos compostos personalizados
- **Maps**: Coleções chave-valor
- **Slices**: Arrays dinâmicos
- **Pointers**: Referências de memória

### Concorrência
- **Mutexes**: Sincronização de acesso
- **Select**: Controle de múltiplos channels
- **Context**: Gerenciamento de cancelamento

### Módulos
- **Go Modules**: Sistema de gerenciamento de dependências
- **Packages**: Organização de código
